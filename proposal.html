1지금 왜 바꾸나요

커뮤니티만으로는 목적이 흐릿합니다

지금 사이트는 "홍보 실무자 커뮤니티"가 중심입니다. 그런데 커뮤니티는 사람이 많이 모여야 돌아가는데, 초반에 활성화가 어렵고 "그래서 이 사이트가 뭘 해주는 곳이지?"가 잘 안 보입니다.

목적이 약함

"무엇을 해주는 곳"인지 한눈에 안 들어옵니다.

활성화가 어려움

커뮤니티는 사람이 모여야 하는데 초반 진입이 힘듭니다.

타깃이 흐림

누구를 위한 서비스인지 뾰족하지 않습니다.

2그래서 이렇게 갑니다

보도자료 배포를 "가장 잘 맡기는 곳"

PR컴을 보도자료(언론홍보) 배포를 도와주는 실무 도구 겸 서비스로 만듭니다. 손님은 이미 보도자료를 뿌리고 있거나, 뿌릴 곳을 찾는 사람들입니다.

"보도자료, 어디에 맡길지 고민이라면 — PR컴이 제일 낫다"
이 한마디를 사이트 전체로 증명하는 것이 목표입니다.
누구를 위해이미 보도자료를 배포하거나, 맡길 곳을 비교하는 실무 담당자 (대행사·일반 광고주가 주 타깃 아님)
경쟁 상대뉴스와이어, 미디어피, 리스토브 같은 보도자료 배포 대행 서비스
이기는 방법① 언론사를 제대로 설명해주는 목록 ② 가격이 투명 ③ 글쓰기부터 배포까지 한 번에
커뮤니티는없애지 않고 뒤쪽 보조 콘텐츠로 이동 (신뢰·검색 유입용)
3가장 큰 무기

"이 언론사가 뭐하는 곳인지" 알려주는 목록

손님은 '공감신문'이 어떤 매체인지 잘 모릅니다. 경쟁사들은 매체 이름만 쭉 나열합니다. 우리는 매체 하나하나를 설명해서, "우리 업종에 맞는지"를 바로 판단하게 해줍니다. 이 데이터는 이미 상당 부분 갖고 있습니다.

항목경쟁사PR컴
매체 정보이름만 나열매체 설명 + 어떤 독자 + 노출 채널
업종 적합도알기 어려움업종별 가능/불가 · 참고사항 표시
가격문의·불투명업종·매체별 가격 공개 + 장바구니
작성직접 작성AI로 초안 작성 → 바로 배포
✅ 이미 가진 자산 — 일반·메디컬·창업·법률·뷰티·헬스·건강식품·블록체인·주식(HTS) 등 업종별 노출채널·참고사항·가격 데이터가 정리돼 있습니다. 여기에 "매체 설명"만 채우면 됩니다.

6핵심 페이지 4개

이 네 개가 사이트의 중심

① 언론사(매체) 목록 간판

업종·노출채널·가격으로 걸러 보고, 매체마다 "어떤 곳인지" 설명. 마음에 들면 바로 배포 담기.

② 보도자료 배포 도구

AI로 기사 초안 작성 → 원하는 매체 선택(장바구니) → 신청/결제. 진행 단계 표시.

③ 가격표

업종 × 매체 가격을 한눈에. 검색·정렬 가능.

④ 커뮤니티 뒤쪽

실무 질문·노하우·자료 게시판. 검색 유입과 신뢰를 위한 보조 콘텐츠.

7만드는 순서

이 순서로 단계별로 만듭니다

준비

기본 뼈대 세팅

개발 환경·폴더·데이터 저장 틀을 표준대로 준비합니다.

1단계

언론사(매체) 목록부터 ⭐

간판이니 제일 먼저. 관리자에서 매체 등록·수정, 손님용 목록/상세 완성.

2단계

보도자료 배포 도구

작성 → 매체 선택 → 신청까지. 가격표 연결.

3단계

홈 새로 구성

배포 도구 + 매체 목록 미리보기 + 차별화로 첫 화면 재구성.

4단계

보조 콘텐츠

인사이트, 커뮤니티(뒤쪽), 오늘의 PR 정보, 문의.

5단계

AI 보도자료 작성 정상화

지금 기사가 제대로 안 나오는 부분을 예전 정상 버전으로 복구·연결.

8개발 기본 규칙

개발팀 표준대로 만듭니다

개발팀이 준 「제작 표준」을 그대로 지켜서 만듭니다. 아래는 쉽게 요약한 것이고, 실제 개발용 상세 규칙은 별도 문서로 함께 전달합니다.

  • 사용 기술 — PHP 8.2 · CodeIgniter 4 · MySQL(데이터베이스). 정해진 표준 그대로.
  • 폴더·이름 규칙 — 표준에 정해진 폴더 구조와 파일 이름 규칙을 지킵니다.
  • 보안 — 로그인 암호화, 잘못된 입력 차단, 파일 업로드 제한 등 기본 보안 규칙 적용.
  • 데이터 정리 — 매체·가격·주문·게시글 등을 표 형태로 나눠 저장(총 12종). 지금 갖고 있는 매체·가격 데이터를 그대로 옮겨 담습니다.
  • 관리자 페이지 — 매체·가격·주문·게시글·문의를 직접 등록/수정할 수 있는 뒷단 화면 포함.
